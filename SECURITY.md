# Security Policy

This repository is for local, authorized reverse-engineering research and reproducible demos.

Please do not report vulnerabilities for third-party targets here. If you find a bug in this project itself, open an issue with:

- affected version or commit
- minimal reproduction steps
- expected vs actual behavior
- whether generated artifacts contain sensitive data

Never attach real session cookies, private API keys, production request payloads, or proprietary target code to public issues.
